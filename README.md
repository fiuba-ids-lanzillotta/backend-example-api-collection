# backend-example-api-collection

Colección de peticiones de [Bruno](https://www.usebruno.com/) para consumir la **Backend Example API**.

## Estructura

- `Alumnos` (CRUD completo)

## Entorno

Usá el entorno `Local` configurado con:

- `protocol`: `http`
- `host`: `localhost:5000`
- `base_url`: `/backend_example_api`

Si el servidor corre en otro puerto, modificalo en `environments/Local.bru`.

## Requisitos

- Bruno instalado.
- API levantada (`backend-example-api`) con la base de datos MySQL corriendo (`docker compose up -d`).

## Uso

1. Abrí la colección en Bruno.
2. Seleccioná el entorno `Local`.
3. Ejecutá las peticiones en el orden deseado.
